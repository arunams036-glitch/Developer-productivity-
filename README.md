Code Clarity
A tool that analyzes code and provides readability/clarity feedback to help developers write cleaner, more maintainable code.

🚀 Features
Analyzes code structure and readability
Highlights complex or hard-to-read sections
Suggests improvements for cleaner code
Simple, easy-to-use interface
🛠️ Tech Stack
TypeScript
